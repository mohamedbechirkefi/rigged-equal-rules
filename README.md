# RIGGED: when equal rules produce unequal outcomes (working title)

**Question.** Can equal rules yield unequal outcomes under different starting distributions?

**Status: M0 (bootstrap and feasibility).** No experiment has run. There are no findings. The protocol in `research/protocol.md` is a draft awaiting the owner's freeze.

## Why it matters

Decision rules such as a single score threshold are often described as fair because they treat everyone the same way. This project studies, in a fully synthetic and transparent setting, whether equally qualified individuals can still face different chances of selection when groups start from different distributions of qualification or are measured with different noise, and how alternative rules trade one fairness criterion against another.

## Scope and claims boundary

Synthetic populations only. Groups A and B are abstract and represent no real or protected group. No real hiring, lending or justice decision is modelled. No fairness metric is presented as universal.

## Data

Synthetic, generated by the project's own seeded code (not implemented yet). External datasets were audited and not used; see `data/manifest.json`.
