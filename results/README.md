# results/

Machine-readable outputs of experiment runs, written by `rigged.runner` and validated against the versioned schemas in `src/rigged/schemas/` (result bundle 1.0.0, run manifest 1.0.0).

- `exploratory/`: **exploratory, simulated, not findings.** Produced before the owner froze any protocol (M2, 2026-11-24): `smoke/` (protocol smoke matrix, JRN-0002), `sizing/` (n = 20,000 on seeds 1000 to 1019, JRN-0003), `degen/` (degenerate-case probe, JRN-0004). Each holds `results.json`, `run_manifest.json`, `tables/`, `figures/`, `report.md` and `report.pdf`.
- `EXP-NNN/`: confirmatory results, written only by `scripts/rigged run --experiment EXP-NNN` after the owner's freeze. None exists.
- `raw/`: git-ignored large outputs, regenerated by script.
