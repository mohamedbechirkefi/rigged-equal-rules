# results/

Machine-readable outputs of experiment runs, written by `rigged.runner` and validated against the versioned schemas in `src/rigged/schemas/` (result bundle 1.0.0, run manifest 1.0.0).

- `exploratory/`: **exploratory, not findings** (seeds 1000 and above). Before the freeze (M2, 2026-11-24, code revision 16e3b4f): `smoke/` (protocol smoke matrix, JRN-0002), `sizing/` (n = 20,000 on seeds 1000 to 1019, JRN-0003), `degen/` (degenerate-case probe, JRN-0004); each also holds `report.pdf`. These three predate the pre-data amendments, so the current code does not reproduce them (M6 reproducibility report). After the freeze: `m3-smoke/` and `m3-sizing/` (M3, code revision 9f464c5, identical in `src/` to b455d59), `exp-003-x/` (JRN-0014) and `m4-confounders/` (JRN-0015, JRN-0016).
- `EXP-NNN/`: confirmatory results, written only by `scripts/rigged run --experiment EXP-NNN` after the owner's freeze: EXP-001 to EXP-004 at code revision b455d59, each with `SHA256SUMS`.
- `raw/`: git-ignored large outputs, regenerated by script.
