# Release checklist

Status: M0. Nothing is released without the owner's explicit approval.

- [ ] Every registered experiment has a truthful standalone report (`research/experiments/EXP-NNN/report.md`).
- [ ] Integrated manuscript complete; PDF compiled with the Typst chain and visually inspected.
- [ ] `manuscript.tex` regenerated from the final Markdown.
- [ ] Claims audit complete; every number traceable.
- [ ] Reproducibility report complete with actual outputs.
- [ ] README, CITATION.cff, NOTICE.md and data manifest current.
- [ ] Demo works offline after initial load; accessibility checks recorded.
- [ ] Articles (`articles/medium.md`, `articles/linkedin.md`) use the same verified results.
- [ ] Owner approval recorded in `research/decision_log.md`.
