## 3. Zero-cost publication toolchain (decision DEC-002)

There is no TeX distribution. PDFs are produced as: Markdown (canonical) to Typst with pandoc, then compiled with the `typst` Python package. `manuscript.tex` is generated from Markdown with `pandoc -s -t latex`, but it is not compiled locally; the repository states this plainly. An exploratory smoke check of this chain was run in M0 (see `progress.md`, 2026-11-24); its PDF was written to a scratch directory and is not committed, because a skeleton has no content worth a PDF.

## 4. Compute budget

The simulation is vectorised NumPy over at most 20,000 individuals per population. The full matrix (about 1,500 runs) is a planning estimate of under 30 minutes on this laptop; the smoke run will measure it. No GPU, no cloud, no paid service.

## 5. Time budget

Five focused development days (planning estimate). Cut order if threatened, following master prompt section 9: optional demo features first, then EXP-003's non-Gaussian shapes, never the controls, the reports or the claims audit.

## 6. Sources and licences

See `research/literature_review.md` (literature) and `data/manifest.json` (datasets). The study uses synthetic data generated by its own code; no external dataset is required. Real datasets were audited only to document why they are not used.

## 7. Risks

| Risk | Likelihood | Mitigation |
|---|---|---|
| The primary hypothesis is analytically implied by the model, so the experiment may look trivial | High | Stated openly in the protocol; contribution framed as quantification, robustness (EXP-003) and explanation, not discovery |
| Typst rendering of pandoc output (tables, equations) needs fixes | Medium | Smoke check done in M0; inspect PDFs in M6 |
| `manuscript.tex` cannot be compiled locally | Certain | Documented; the PDF comes from Typst |
| Readers misread synthetic groups as real groups | Medium | Abstract labels A and B; claims boundary in every report and in the demo |
| Demo build needs npm packages (network at install time) | Medium | Pin versions at least two weeks old; fall back to a dependency-free static page if needed |
